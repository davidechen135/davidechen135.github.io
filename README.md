# ChenDavide — personal homepage

An English-only, static GitHub Pages homepage with an interactive inverse-kinematics robot arm and filterable public project collection.

- Clear project categories and direct repository links.
- Responsive layouts and reduced-motion support.
- Keyboard-accessible target sliders, plus pointer interaction.
- No build step or runtime dependencies. Fonts fall back to system fonts.

## Preview

Run `python3 -m http.server 8080` from this directory and open http://localhost:8080.

## Content

Edit the project collection in `app.js` and the introduction in `index.html`. Project summaries follow the linked public repositories. The robot arm is an illustrative kinematics demo, not a measured robotics result. No unpublished papers or internal experiments are included.

## Hosting

Published from the `main` branch root using GitHub Pages.
